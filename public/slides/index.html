やること / やらないこと

やること

  • 過去〜現在の健康データを可視化
  • いまの位置と進み方を共有
  • 医師が選んだ具体行動をA4で渡す

やらないこと

  • 病気の確定診断
  • 疾病発症確率の自動計算
  • AIが治療方針を決定
Compass Score ≠ 発症リスク

画面① 健康の現在地

  • Compass Score … 5視点の総合イメージ
  • Health Velocity … 変化の速さ
  • 方向 … 改善 / 安定 / 悪化

最初の30秒で「いまどこにいるか」がわかるように設計

画面② 5領域レーダー

  • 血管 / 代謝 / 肝臓 / 腎臓 / がん予防
  • 高いほど良好（0–100）
  • 発症確率ではないことを画面に明記
  • Risk Engine は将来用に分離（今は未実装）

画面③ 3年間の変化

  • 体重・HbA1c・血圧などを切替表示
  • 「別々の異常」ではなく流れとして共有
  • 画像所見（脂肪肝・CTR）も時系列で提示

リアルタイム反映

Action Prescription Builder

食事・運動パーツは年齢だけでなく ADL / 活動量 / 関節 / サルコペニア等で推薦。減量食を全員に出さない。

持ち帰る 90日プラン（A4）

  • 90日目標（例：78kg → 75kg）
  • 食事：何g・何時・週何回まで具体化
  • 運動：分×回×週 まで記載
  • 毎日チェック / 90日後の確認項目

「バランスよく」「適度に」は禁止。
医師承認後に印刷。

全体の流れ

現在地 → レーダー → 推移 → 画像所見 → Action Builder → メッセージ

まとめ

01

診断ではなく、地図を共有する

Score は発症確率ではない。現在地・方向・行動を同じ画面で見る。

02

Action は Parts × 医師の選択

医学ロジックは Library / Modifiers / Safety に分離。最終決定は医師。

03

明日からの具体行動を1枚で渡す

抽象アドバイスではなく、患者が家で実行できる90日プラン。
